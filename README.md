# AI CHATBOT FOR COLLEGE FAQs

## Problem Statement
- College students frequently need information about admissions, courses, fees, exams, timetables, departments, scholarships, hostel facilities, placements, events, exam and college rules.
- Students have to manually search through these sources or contact staff, which can be time-consuming and repetitive.
- The project solves this problem by providing a single AI-powered chatbot where students can ask questions in natural language and receive relevant answers.

## Objective 
- Develop an AI chatbot that automatically answers frequently asked college-related questions.
- Allow students to ask questions using normal conversational language instead of searching through documents.

## AI/ML Type
- The project is primarily an NLP (Natural Language Processing) application.
- It can be classified as a Conversational AI / Generative AI system, depending on how the chatbot generates answers.
